Usage: lsatfetch get CONFIG [ARGS]

Create a Landsat dataset based on the provided configuration.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  CONFIG --config              Path to the configuration YAML file.         │
│                                 [required]                                   │
│    VERBOSE --verbose            Enable verbose (DEBUG) logging. Defaults to  │
│      --no-verbose               False. [default: False]                      │
│    DOWNLOAD --download          Enable downloading of tiles. If False, only  │
│      --no-download              already downloaded tiles are processed.      │
│                                 Defaults to True. [default: True]            │
│    POSTPROCESS --postprocess    Enable post-processing (compression to JP2). │
│      --no-postprocess           Defaults to False. [default: False]          │
│    QUALITY --quality            JPEG2000 compression quality (1-100).        │
│                                 Defaults to 50. [default: 50]                │
│    N-WORKERS-DL --n-workers-dl  Number of parallel download jobs. Defaults   │
│                                 to 4. [default: 4]                           │
│    N-WORKERS-PP --n-workers-pp  Number of parallel preprocessing jobs.       │
│                                 Defaults to 4. [default: 4]                  │
╰──────────────────────────────────────────────────────────────────────────────╯
